# Git Workflow

## Rules

- Inspect the working tree before making changes.
- Preserve unrelated user changes.
- Keep changes scoped to the requested task.
- Run relevant verification before proposing a commit.
- Do not commit, push, publish, or open a pull request without user authorization.
- Do not rewrite history or use destructive Git operations unless explicitly requested.
- Report modified files and verification results at handoff.
