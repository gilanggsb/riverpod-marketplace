# Planning and Execution

Use a process proportional to task complexity and risk.

## Simple Work

For small, low-risk, and easily reversible tasks:

1. Inspect the relevant context.
2. Implement the requested change.
3. Run proportionate verification.
4. Report the result and any remaining risk.

A separate plan file or approval checkpoint is not required unless requested.

## Complex or Risky Work

For multi-phase, high-risk, destructive, or broadly impactful work:

1. Create a persistent Markdown plan with checkboxes.
2. Define scope, assumptions, validation, and rollback.
3. Implement one reviewable phase at a time.
4. Update the plan after each completed phase.
5. Request review before continuing when the plan or user workflow requires a checkpoint.
